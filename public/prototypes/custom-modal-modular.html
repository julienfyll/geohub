Analyse Comparative des 2 Architectures d'Intégration

Critère Clé Solution 1 : Onglets Racine (Segmented Control) Solution 2 : Tiroir Adaptatif (Morphing In-Situ)
Stabilité visuelle ✅ Parfaite : Chaque vue a sa propre structure, zéro saut de hauteur imprévisible. ⚠️ Variable : La modale s'étire ou se rétracte selon que Métro est coché ou non.
Gestion Multi-packs ✅ Zéro conflit : Dans l'onglet 1, le joueur combine tous les packs qu'il veut sans ambiguïté. ⚠️ Conflit possible : Si le joueur coche Métro + France, le mode Retrace doit se désactiver.
Scalabilité future (RER, Frontières) ✅ Immédiate : Il suffit d'ajouter un 3e onglet ou un sélecteur de mode dédié. ❌ Complexe : Risque d'empiler des tiroirs conditionnels qui surchargent la modale.
Clarté pour le joueur ✅ Évidente : Le joueur choisit d'abord *À quoi il veut jouer*, puis règle les détails. Intéressante si on veut tout garder sur un écran unique au prix de la densité.
